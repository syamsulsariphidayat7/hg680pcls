HG680PCLS

LED Control & Ping Monitor · STB HG680P

Memuat…

LED Power

Pola kedip LED power. Offline = merah berkedip, Online = hijau berkedip, Heart = detak kuning-hijau, Disko = cepat warna-warni.

LED LAN

Pola kedip LED LAN, aktif saat koneksi terdeteksi online.

LED Status

LED ketiga (pin default 518) — LED tunggal, tidak ikut status koneksi. Detak = kedip pelan sebagai tanda service hidup (kalau LED diam, service bermasalah). Nyala = terang terus. Mati = pin tidak digerakkan sama sekali — pilih ini kalau di unitmu pin 518 ternyata bukan LED.

Ping Target

Target aktif (klik untuk hapus)

Tulis target, pisahkan dengan spasi (maks 8; huruf/angka, titik, strip, garis bawah, titik dua). Tiap host tampil dengan status inline (dot + latensi), live.

Interval Cek

5 detik

Jeda antar pengecekan ping (1–60 detik). Makin kecil makin responsif, makin besar makin hemat resource. Angka di atas bisa diklik untuk lompat ke nilai itu.
